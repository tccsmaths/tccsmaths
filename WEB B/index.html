檔案目錄架構說明

本門戶網站採用模組化 `.html` 檔案架構。只需將產生的 HTML 遊戲檔案放置於與 `index.html` 相同的根目錄下，即可直接在卡片中關聯與開啟。

1 現有已發佈遊戲檔案對照

2 如何解鎖或新增新課題遊戲 (準備中 → 即可遊玩)

  1. 點擊編輯本 index.html 檔案中的 JavaScript 數據陣列 topicsData。
  2. 將對應課題的 status 屬性由 'upcoming' 修改為 'available'。
  3. 在該課題的 games 陣列中新增遊戲連結物料，例如： 
    { 
  name: "百分數應用互動研習", 
  url: "P6_Percent_App.html", 
  icon: "fa-percent", 
  badge: "新發佈" 
}
  4. 保存檔案並重新整理網頁即可自動完成掛載與發佈！
